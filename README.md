# Customer Churn Prediction

## Project Overview
This project uses Machine Learning to predict customer churn in the telecommunications industry. It aims to identify customers who may leave the service and help businesses improve customer retention.

## Objectives
- Analyze customer churn patterns.
- Clean and prepare customer data using Python.
- Explore factors associated with customer churn.
- Train and compare Logistic Regression and Random Forest models.
- Evaluate model performance using classification metrics.
- Develop business recommendations for customer retention.

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- GitHub

## Dataset
The project uses a publicly available IBM Telco Customer Churn dataset.

## Machine Learning Models
1. Logistic Regression
2. Random Forest Classifier

## Model Evaluation Results

| Metric | Logistic Regression | Random Forest |
|---|---:|---:|
| Accuracy | 80.41% | 78.78% |
| Precision | 65.41% | 62.71% |
| Recall | 55.61% | 49.47% |
| F1-Score | 60.12% | 55.31% |
| ROC-AUC | 84.25% | 82.09% |

Logistic Regression performed better than Random Forest across the reported evaluation metrics.

## Business Recommendations
- Identify customers at risk of leaving.
- Offer suitable retention plans to at-risk customers.
- Review contract options and customer concerns.
- Improve customer support and service quality.
- Monitor churn predictions regularly.

## Project Files
- `Customer_Churn_Prediction.ipynb`: Analysis, preprocessing, model training, and evaluation.
- `customer_churn_predictions.csv`: Customer churn prediction results.
